# Agent Guidelines & Project Rules

## Repository & Commit Rules

1. **Auto-Push After Every Change**:
   - After making any code or documentation changes within this repository (`SATIS_Shift_Sync`), immediately commit and push the changes properly to the GitHub repository.

2. **Concise Commit Messages**:
   - Commit messages MUST be very, very concise (short, precise, and direct).

3. **Forbidden Term in Commit Messages**:
   - NEVER use the phrase or term `"word"` (or `"Word"`, `"WORD"`) in any commit message when pushing to the GitHub repository.
